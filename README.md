# Code repository for the E1 Dynamics of Complex Fluids by Kogen Nobori.

Please refer to `DDM_main.py` for the main script for the analysis. This `DDM_main.py` conducts batch analysis in a folder, and it is supplemented by `core.py` and `util.py`. `util.py` contains many fundamental classes and functions such as fitting with least_squares regression or RANSAC algorithm used in the code. `core.py` includes the core calculation processes in the analysis. The Python scripts include references where relevant.



# DDM
Python code to perform Differential Dynamic Microscopy

To install:

`pip install -r requirements.txt`
